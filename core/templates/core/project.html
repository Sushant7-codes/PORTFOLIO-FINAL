Retail POS
Management System

Full-stack point-of-sale application — inventory, sales tracking, billing, and multi-role user access. Built end-to-end as my 8th semester major project, from schema design to deployment on Render with Cloudinary for media and PostgreSQL for data.

View live system
What it does
Replaces spreadsheet-based retail management. Staff, managers, and admins each get a scoped view via role-based access control built on Django's group permissions.
A decision I'd revisit
Used WhiteNoise to serve static files directly from Django — fine at this scale, but it's the first thing I'd swap for a CDN once traffic grows.

Sports E-Commerce
Platform

A marketplace for sports gear — jerseys, balls, and equipment. Sellers list their items, buyers browse and purchase. Built to understand the full Django request–response cycle in a real shopping context: cart state, order placement, session handling, and role-based seller vs. buyer views.

View live store
What it does
Sellers can list sports items with images and prices. Buyers can browse, add to cart, and place orders. Separate dashboards for each role via RBAC on Django's permission system.
What I learned
Not a tutorial follow-along — I wanted to debug the full flow myself. Cart state, session management, and order logic all written from scratch to actually understand how they connect.
Stack
Python Django SQLite Tailwind CSS HTML RBAC PythonAnywhere
Live — Team Project · 7th Semester

Event Management
System

Public event platform — anyone can create and organize events, with a freemium model: free tier lets you host a limited number of events, paid subscription unlocks more. Built with a team of three; my responsibility was the entire data layer — schema design, entity relationships, and the PostgreSQL database that the Next.js frontend and Node.js API both depend on.

View live system
What it does
Any user can sign up, create events, and manage registrations. Free tier covers a limited event count — users upgrade to a paid subscription to unlock more events.
My contribution
Owned the full database layer — schema planning, table relationships, and SQL that a Node.js API I didn't control would query reliably without breaking.
Stack
PostgreSQL Next.js Node.js SQL Schema design Freemium

Live - Major Project

Retail POS
Management System

A full-stack point-of-sale application covering inventory management, sales tracking, billing, and multi-role user access. Built end-to-end as my 8th semester major project - from database schema through to deployment on Render with Cloudinary for media and PostgreSQL for data.

View live system
Problem solved
Small retail operations typically manage inventory and sales in spreadsheets. This replaces that with a structured system that enforces role-based access staffs, managers, and admins each see only what they need.
Technical decisions
Custom Django user model with a group-based permission system. Cloudinary for product image storage so the deployment stays stateless. WhiteNoise for static files - no separate CDN needed at this scale.
Stack
Python Django PostgreSQL Tailwind + DaisyUI Cloudinary Render RBAC
